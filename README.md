# Хэзэнштейн — сайт-презентация

Статический сайт-презентация приложения **Хэзэнштейн**: заметки, задачи, календарь, желания с ИИ-наставниками и карта мыслей.

**Живой сайт:** https://lexxgreat.github.io/hz/
**Приложение:** https://lexxgreat.github.io/hz3/

## Структура

```
index.html      — одна страница: hero, проблема, магия ввода, возможности,
                  желания (4 блока), фокус, календарь, карта мыслей,
                  ИИ-чат, сравнение, CTA
css/style.css   — дизайн-система (тёмная фирменная палитра #060918 / #6C47FF,
                  всплески #00D4FF и #FFD166; Manrope + Inter)
js/main.js      — reveal-анимации, активный пункт меню, мобильное меню
assets/         — 12 реальных скриншотов приложения (WebP, ~513 КБ суммарно)
favicon.svg     — фирменная иконка «ХЗ»
```

## Технологии

Чистые HTML / CSS / JS без зависимостей. Шрифты — Google Fonts (Manrope, Inter).
Скриншоты сняты с живого приложения (Playwright), конвертированы в WebP.

## Деплой

GitHub Pages из ветки `main` (root). Изменения публикуются обычным push.
